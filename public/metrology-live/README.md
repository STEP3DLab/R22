# Метрология LIVE

Интерактивная лаборатория цифровой метрологии для курса Технопарка РГСУ.

Сайт: https://step3dlab.github.io/R22/public/metrology-live/

Откройте index.html в браузере — установка и интернет не требуются. Данные синтетические. Результаты теста обрабатываются локально и скачиваются текстовым файлом; серверного сбора ответов нет.

## Разделы

1. Повторяемость и постоянное смещение.
2. Допуск и интервал неопределённости.
3. 3D-облако точек: плотность, шум, пропуски.
4. Тепловое расширение.
5. Маршрут обратного проектирования.
6. Тест из 12 вопросов с объяснениями.

Для занятия используйте маршруты на 5, 15 и 30 минут, режим лекции и полноэкранную кнопку. Попросите слушателей сначала предсказать результат, затем измените параметр и обсудите наблюдение.

## Проверка

Проверены синтаксис JavaScript, рендеринг шести разделов с имитацией DOM, расчёт теплового расширения, граничные решения приёмки, прохождение теста и последовательность этапов. Визуальная проверка в настоящем браузере в среде разработки недоступна.
